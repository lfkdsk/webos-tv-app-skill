## 按键路由

- 所有按键走一个捕获阶段的 `keydown`,页面不要各自判断键码。
- 设置 `"disableBackHistoryAPI": true`,自己处理 461;在根页面调 `PalmSystem.platformBack()` 交还系统。不要直接杀掉应用。
- 退格(8)必须单独处理,否则输入框里按退格会变成返回。
- 需要吞掉某个键(比如唤醒屏保的那一下)时,用捕获监听加 `stopImmediatePropagation`。[代码]

## 焦点

- **用虚拟 `.focused` 类,不用 DOM focus。** 避免弹出系统键盘。[说法]
- **按几何选下一个元素,不按 DOM 顺序。** 海外哔哩的评分是 `primary + secondary*2`,同组减 1;EmbyTV 用 `CROSS_PENALTY = 4`。
- **组内记忆上次焦点,但只在按键方向上才复用。** 否则按下会跳到上面。`focus.js:93-108`
- **Magic Remote 是真指针。** hover 移动焦点但不滚动页面,click 先聚焦再触发;移动小于 24px 的忽略,它会上报抖动。
- **卡片被隐藏时要把焦点移走,** 否则焦点会落到看不见的元素上。
- **输入框只在按 OK 时才打开键盘;** 返回和上下键让它失焦,否则方向键被困住。
- **弹层要真的困住焦点。** EmbyTV 的 `spatial.move` 扫全部元素,模态框里焦点能跑出去,这是已知缺陷。
- **内容会刷新的弹层:** 用签名判断是否重建,重建后按 `data-key` 恢复焦点。

## 滚动

- 根节点 `overflow:hidden`,只滚动带 `data-scroll` 的祖先,留 60px 边距,返回时瞬间恢复位置。
- 用 `behavior:'instant'`。平滑滚动时长按方向键会超过视口。[说法]
- 虚拟网格在每次焦点变化时重新读 `scrollTop`,否则迟到的滚动事件会让焦点卡在最后一行。多渲染 2 行。[说法]

## 布局

- html/body 固定 1920×1080,viewport `width=1920`,appinfo 里 `resolution:"1920x1080"`。
- 字号:正文 28px,卡片标题 26,副标题 22,字幕 44。焦点:放大 1.07 倍加 5px 描边。
- 页面边距 72-80px。这些项目都没有专门的安全区逻辑。
- 列宽别算错:5 列是 1696/5 = 339px,放 360px 的卡片会重叠(启动器 `65fbbab`)。
- 透明的系统图标给 `.glyph` 类,按 62% 高度居中。
- 弹层背景要不透明。半透明时二级菜单和上级重叠难读(`b063795`)。

## 性能

- 请求缩略图,用懒加载和异步解码;海报最大宽度按列宽 × 2。
- 被压在下面的页面 `display:none`。
- 弹幕用 WAAPI 的 transform,先批量插入再测量;同屏上限 40,每 200ms 最多 12 条。
- **防抖 D-pad:** 切标签延迟约 220ms 再加载;快进累积 420-700ms 再提交一次 seek。每次写 `currentTime` 都可能重开解码器,还会引发一波 Range 请求。
- 统计数据只在面板可见时轮询。
- 启动包要小,hls.js 这类动态加载。

## 构建目标

- esbuild IIFE,`target: chrome108`,够保守。EmbyTV 用 `chrome120`。
- Vite 要 `base: './'`,因为页面从 `file://` 加载。
- 更老的目标还要去掉 `:has()` 这类 CSS。
